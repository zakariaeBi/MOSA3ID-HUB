🧭 About the Project
MOUSA3iD HUB is a dual-purpose web platform that combines two essential pillars of personal performance:

😴 Sleep — Calculate your optimal sleep rhythm using science-backed sleep cycle logic.

🎯 Focus — Stay locked in on your work with a dedicated focus timer and distraction-free environment.

The goal is simple: help you rest better so you can work better.

✨ Features
😴 Sleep Module
The Sleep section helps you plan your rest around the human body's natural 90-minute sleep cycles.

What it does:

🕐 Bedtime Calculator — Enter the time you need to wake up, and get the ideal times to fall asleep.

⏰ Wake-Up Calculator — Enter when you're going to bed, and get the best times to wake up.

🔄 Sleep Cycle Logic — Based on 90-minute cycles + ~15 minutes to fall asleep.

✅ Waking between cycles — Avoids waking up mid-cycle (which causes grogginess).

Example:

If you need to wake up at 7:00 AM, ideal bedtimes are:
9:45 PM · 11:15 PM · 12:45 AM · 2:15 AM

🎯 Focus Module
The Focus section is built to help you enter deep work mode.

What it does:

⏱️ Focus Timer — A Pomodoro-style timer (customizable work/break intervals).

🔕 Distraction-Free Mode — Minimal UI to keep your eyes on the task.

🔔 Break Reminders — Alerts you when it's time to rest your mind.

📊 Session Tracking — Keep count of your completed focus sessions.

Default Pomodoro Setup:

Phase	Duration
Focus	25 min
Short Break	5 min
Long Break	15 min
🚀 Getting Started
Prerequisites
You only need a modern web browser. No installation required.

bash
# If you're running it locally:
git clone https://github.com/zakariaeBi/MOSA3ID-HUB.git
cd mousa3id-hub
Then open index.html in your browser — or use a live server:

bash
npx serve .
🛠 How to Use
Using the Sleep Calculator
Go to the Sleep tab.

Choose your mode: "I want to wake up at..." or "I'm going to bed now".

Enter the time.

Get your list of ideal sleep/wake times.

Pick the one that fits your schedule. 😴

Using the Focus Timer
Go to the Focus tab.

Select your session length (default: 25 minutes).

Click Start.

Work until the timer ends — no tabs, no distractions.

Take your break when prompted. Repeat. 🎯
